Privacy Policy

Effective September 14, 2026

YiwuSupply is an independent, local-first sourcing companion. The current mobile release does not require an online account and does not send personal or sourcing data to YiwuSupply or TC Safa servers.

Data stored on the device

The app stores the local profile name, shops, products, offers, collections, visits, notes, photos, and app settings in app-private storage on the phone. The local PIN verifier and optional AI-provider API keys are held using platform secure storage. Removing the app removes its local app data according to the phone platform's behavior.

Device permissions

  • Camera and photo access are used only when the user captures or selects sourcing images or scans a transfer QR code.
  • Foreground location is optional and is used during Quick Capture to save a shop coordinate. The app does not request background location.
  • Local-network access is used only when the user starts a direct phone-to-phone transfer.

Direct phone transfer

When the user explicitly starts a move, encrypted workspace records and media travel directly between two phones on the same private Wi-Fi network or personal hotspot. The transfer does not pass through a YiwuSupply server. PIN verifiers, AI API keys, sessions, settings, caches, and logs are excluded.

AI provider keys

The Settings screen can store optional API keys for supported AI providers. The current release does not make AI requests. A future AI feature will require clear user action and an updated privacy disclosure before transmitting content.

Analytics, advertising, and tracking

The current release contains no advertising SDK, analytics SDK, or cross-app tracking. YiwuSupply does not sell user data.

Contact and changes

Privacy questions may be sent to dev@tc-safa.com. This policy will be updated before any future cloud account, sync, server storage, analytics, or AI transmission becomes active.

YiwuSupply is an independent buyer tool and is not affiliated with or endorsed by Yiwu International Trade Market.
