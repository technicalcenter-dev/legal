YIWUSUPPLY

Privacy Policy

Effective September 15, 2026; updated October 28, 2026

YiwuSupply is an independent, local-first sourcing companion. The current mobile release does not require an online account and does not send personal or sourcing data to YiwuSupply or TC Safa servers.

Data stored on the device

The app stores shops, products, offers, collections, visits, quotation history, notes, photos, attachments, and app settings in app-private storage on the phone. Optional AI-provider API keys are held using platform secure storage. Removing the app removes its local app data according to the phone platform's behavior.

Device permissions

  • Camera and photo access are used only when the user captures or selects sourcing images.
  • Foreground location is optional and is used during Quick Capture to save a shop coordinate. The app does not request background location.
  • Internet access is used for requested AI analysis, separately enabled automatic product-photo suggestions, explicitly requested shop recaps, or requested supplier-draft translation. Manual saving works without internet access.

Version 1.2.0 beta: documents, follow-ups and backups

Documents selected through the system file picker are copied into app-private storage and linked to a shop. Follow-ups, due dates, favourites, unfinished drafts and original business-card text are also stored locally. Optional reminders use the device's notification service; YiwuSupply does not run a push-notification server.

You can create and share a local backup containing your sourcing records, photos, documents, drafts and portable settings. In versions before 1.5.0, backup files are not encrypted by YiwuSupply. Version 1.5.0 adds optional password protection as described below. API keys, sessions and device permissions are excluded. Save backups somewhere private. If you choose a cloud drive, messaging app or another destination through the system file/share interface, that service receives the selected file under its own terms; this is your chosen export, not automatic YiwuSupply cloud sync.

Restoring a backup replaces the local workspace after confirmation and preserves a pre-restore recovery copy. Deleting a shop removes its locally managed information after confirmation. Deletion or uninstalling the app does not remove copies you exported, copies shared with recipients, or requests already processed by an AI provider.

AI in version 1.2.0 beta

Optional AI uses only OpenAI with your own API key held in platform secure storage. Business-card extraction uses GPT-6 Luna and sends only the selected business-card images, up to four compressed images depending on the platform. The editable result prioritizes English while retaining original Chinese facts separately. Explicit detailed analysis uses GPT-6.1 Sol and sends the selected capture images and typed context shown by that workflow. Nothing is sent automatically. Document attachments, backups, your full shop library, personal ratings and saved GPS coordinates are not automatically sent for card extraction.

Version 1.3.0 beta: products and optional automatic AI

Products, photos, prices, dated quotation history, notes and quotation files can be kept inside each shop on the device. Confirming or removing a comparison link is your choice; AI never automatically merges products or certifies equivalent quality.

Automatic product suggestions are a separate optional setting with their own disclosure and permission. When enabled, newly added product photos can be sent to OpenAI using your own key: up to two selected product images for descriptions, and the source image plus up to three shortlisted saved product images for a possible-match check. Visible information within those images is included. Structured shop contacts, private notes, ratings, quotation attachments and GPS coordinates are not included in these automatic requests. GPT-6 Luna is used for this workflow; internet access and API charges may apply. Enabling the setting does not analyse the entire historical library.

Automatic requests set store:false, but this is not a guarantee of zero provider retention. OpenAI handles your account and requests under its terms and settings. Turning automatic suggestions off stops new automatic requests and rejects late results. Clearing the key prevents future requests. Completed descriptions remain locally until removed with their data; provider-side retention or deletion is managed through your provider account. Detailed analysis remains an explicit action using GPT-6.1 Sol.

You can select products for a PDF and choose whether it contains notes and supplier contact details. The native share interface sends the file only to the destination you choose. Backup archives also contain product notes, quotation history, selected documents and confirmed comparison links. They exclude API keys, device permissions, automatic-AI consent and guide progress. Restoring does not enable automatic AI on a new device. The first-use and replayable practice guide uses device-local progress and does not create practice shops in your business records.

Version 1.4.0 beta: invoice photos and optional shop recaps

Invoice images from the camera or selected photos are copied into app-private attachments. An optional PDF photo copy contains the source image without retyping, translating or reconstructing financial amounts. These documents and copies remain local unless you choose an export or sharing destination.

Shop recaps are a separate optional action with disclosure and consent for each request. If you proceed with your own OpenAI key, GPT-6 Luna receives the selected snapshot's product identifiers, names and product notes to arrange the saved records. Notes can contain amounts, contacts or other details you wrote. Structured price fields, shop notes, GPS coordinates, contacts and images are not included in these recap requests. Review the disclosure before proceeding; internet access and API charges may apply. A recap request is never enabled by the automatic product-photo setting.

The app accepts only verified source identifiers and displays the original saved facts and exact prices, without model-generated financial prose or totals. Dated snapshots are stored locally, retain their saved time zone and cutoff, and do not overwrite earlier recaps. They are current-facts snapshots, not a complete activity log or financial advice. Recap history is included in local backups and removed with its shop. Keys and recap consent are excluded from backups. Requests set store:false, which is not a zero-retention guarantee; provider-side processing, retention and deletion remain subject to your OpenAI account and its terms.

Version 1.5.0 beta: local sourcing tools and recovery

Local search, sourcing projects and requirements, sample stages, quotation terms, arrival landmarks and follow-up queues use saved data on the device. They do not require an account or YiwuSupply server. Selected PDF, CSV and Excel handoffs contain only the records and optional fields you select; the native share interface sends those files only to your chosen destination.

Deleting a shop in version 1.5.0 moves its linked records and privately stored files to Recently Deleted. They remain on the device and in full backups until you restore the shop or confirm permanent deletion. There is no automatic expiry. Permanent deletion does not remove copies already exported, shared with recipients or processed by an AI provider.

You can optionally password-protect a full local backup using authenticated encryption provided by the platform. The password is not saved by YiwuSupply and a forgotten password cannot be recovered by the app. An unprotected backup remains readable without a password, so keep it private. Creating a backup or opening Share does not prove an external copy exists; Verify a saved backup reads the file you select. Backups include recoverable deleted shops, projects, samples and media, but exclude AI keys, sessions, device permissions and AI consent. They are not automatic cloud sync.

English and Chinese supplier-message templates work offline. A separate optional Translate and preview action sends only the draft text to OpenAI GPT-6 Luna using your own key, after per-request disclosure and consent. Recognized numbers and identifiers are replaced with placeholders and restored locally after validation. Other wording may still contain sensitive information you typed; masking is not guaranteed anonymization. Photos, attachments, the full library and saved GPS coordinates are not included in this translation request. Requests set store:false, which is not a guarantee of zero provider retention. Review both drafts before copying or sharing. The app does not automatically send a supplier message or modify saved quotations from the translated draft.

AI provider keys in earlier versions

Versions before 1.2.0 can store optional keys for OpenAI, Claude/Anthropic, Google Gemini, and DeepSeek. Nothing is sent automatically. When the user selects a provider and taps Analyze, YiwuSupply sends the current typed capture context directly to that provider. OpenAI, Claude, and Gemini may also receive compressed copies of up to four selected capture photos; DeepSeek receives typed context only. The provider processes that content under the user's account and its own terms and privacy policy. Suggestions remain editable and are stored locally only when the user saves.

The app does not keep a separate server copy of an AI request or response. The selected provider may retain account and request data according to its own terms. Users can revoke future AI use by clearing the provider key in Settings and not using Analyze; provider-side access, retention, or deletion requests must be managed through the user's account with that provider.

Analytics, advertising, and tracking

The current release contains no advertising SDK, analytics SDK, or cross-app tracking. YiwuSupply does not sell user data.

Contact and changes

Privacy questions may be sent to dev@tc-safa.com. This policy will be updated before any future cloud account, sync, server storage, or analytics becomes active.
