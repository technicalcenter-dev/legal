Support

For help with YiwuSupply testing builds, contact dev@tc-safa.com.

Before contacting support

  • Include the platform: Android or iOS.
  • Include the app version and build number.
  • Describe what you expected and what happened.
  • Do not send AI API keys, PINs, or sensitive sourcing records.

YiwuSupply has no server account in this release. A profile and six-digit PIN belong only to the device on which they were created.
